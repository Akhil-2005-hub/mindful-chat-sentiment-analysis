## Suggested LinkedIn post

I’ve built **Mindful Chat**, a full-stack chatbot project exploring account security, conversational interfaces, and sentiment analysis.

The app uses React and Flask, stores user-specific conversations with SQLite (with a MySQL configuration option), hashes passwords, and protects chat routes with JWT authentication. It classifies text as positive, neutral, or negative using a lightweight sentiment approach, then selects a simple response template.

A key lesson from building it: sentiment labels are only rough signals. They can miss context, sarcasm, and mixed feelings, so they should not be treated as psychological assessments.

The project helped me practice API design, authentication, data access control, database integration, and full-stack development. I’ve included setup steps and tests so others can run it locally.
